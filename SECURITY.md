# Security

We take the security of the packages we maintain seriously. If you have found a security issue with any of our projects please email us at security@torchbox.com 
so we can work together to find and patch the issue. We appreciate responsible disclosure with any security related issues, so please contact us first before creating a Github issue.

If you want to send an encrypted email (optional), refer to https://torchbox.com/.well-known/security.txt for details.
